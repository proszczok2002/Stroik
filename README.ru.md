# Stroik 1.21 — Руководство

- Ля контроктавы получает ту же поддержку обертонов, что и более низкие ноты. Обе платформы используют одинаковый тембр без переноса октавы. Слышимость баса зависит от динамиков.
- Классический гибрид запускается сразу без учебных подсказок. Для начинающих сначала читаются подсказки. Поведение Windows сохранено и добавлено в Android.
- Пауза после результата теперь 0–60 секунд, включая 1 и 2. При 0 эталон включается сразу после фактического окончания речи. Новый стандарт — 0; сохранённые паузы Windows не сбрасываются. В Android добавлены ползунок и ввод числа.
- Результат произносится полностью до повторного эталона и разрешения перехода. В гибриде нужны верный результат и два удара с подтверждённой высотой. В режиме камертона сохранён акустический жест.
- В классическом списке Android убраны положения клавиш. Добавлены описания методов для начинающих и выбор чёрных клавиш влево/вправо. Результаты и подсказки читает синтезатор приложения даже с TalkBack, чтобы отслеживать конец речи; TalkBack управляет навигацией.

Доступный тюнер Windows для незрячих, слабовидящих и зрячих музыкантов.
Язык и тёмная тема выбираются в настройках. Языки: Polski, English, Deutsch,
Русский, Français, Español. Выбор сохраняется в профилях JSON.

## Методы

- Камертон: эталон для настройки на слух, вручную или автоматически.
- Электронный тюнер: включите микрофон, сыграйте ноту и заглушите её.
  Результат сообщает направление и отклонение.
- Гибрид с динамиками: эталон и микрофон работают по очереди. После результата
  камертон ждёт окончания речи и выбранную паузу 0–60 секунд (по умолчанию 0).
  В виде для начинающих сначала читаются советы.
- Гибрид с наушниками: эталон и микрофон одновременно. Прослушивание микрофона
  включайте только в наушниках, чтобы избежать обратной связи.

## Управление

Alt+N или Ctrl+N — следующая нота по плану, с Shift — предыдущая. В списке нот
вверх/вниз выбирают белые клавиши, влево/вправо — только чёрные. I/S выбирают
повышенные ноты. Alt+U — одиночный удар вручную или пауза/продолжение автомата.
Числовые поля принимают точку и запятую; вверх/вниз меняют значение.
Ctrl+S сохраняет профиль, Ctrl+Q закрывает. F1 открывает советы с доступом
с клавиатуры. Классический вид краткий; вид для начинающих содержит пояснения
и расположение клавиш.

В режиме камертона микрофоном управляет только флажок двойного удара.
Сначала требуется тишина; эталон не считается жестом. С этим жестом интервал
автоматических ударов не короче 6,5 секунды. NVDA 2024.1 и новее сообщает
завершение начальных советов; состояние речи требует NVDA 2026.3.
Для других дикторов есть кнопка запуска после советов.

## Инструменты и измерение

Фортепиано, гитара, укулеле, скрипка, бас и хроматический режим. Диапазон
фортепиано A0–C8, начальная нота — соль первой октавы. Квинта и октава строятся
вверх: до первой + соль первой или до второй. Совместное измерение
экспериментальное: обертон может имитировать вторую ноту. Проверяйте отдельно.
В равномерно темперированных квинтах возможны биения; фортепиано может
требовать растянутых октав.

Слишком слабые или сильные удары искажают показания. Играйте ровно, без
перегрузки, настройте чувствительность. 440 Гц — стандарт; перед повышением
натяжения старого инструмента нужен осмотр мастера. Коррекция микрофона —
только по известному эталону. Звук не сохраняется. Обертоны помогают самым
низким нотам, но маленькие динамики ограничены. Красный — расстройка,
зелёный — в допуске; текстовое описание остаётся доступным.

## Профили, обновления и проект

JSON хранит метод, инструмент, ноту, язык, тему и параметры обновлений.
Автопроверку можно отключить и изменить её интервал. Новая версия показывает
изменения; загрузка проверяется по SHA-256. EXE заменяется и программа
перезапускается. Храните программу в папке с правом записи.
