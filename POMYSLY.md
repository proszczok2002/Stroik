# Pomysły / Ideas

## Osobna zakładka Pianino / Separate Piano tab

PL: Pomysł z informacji zwrotnej 2026-11-13: granie prostych melodii barwą kamertonu w osobnej zakładce. Potrzebna możliwość ponownego uderzenia tej samej nuty, dostępne sterowanie klawiaturą i opisy dla czytnika ekranu. Funkcja do osobnego zaprojektowania; nie jest częścią poprawki współbrzmień. Obecnie Alt+U w ręcznym trybie kamertonu powtarza wybrany dźwięk.

EN: Feedback from 2026-11-13 suggests a separate Piano tab for playing simple melodies with the fork sound. It needs repeated strikes of the same note, keyboard access and screen reader labels. This needs separate design and is not part of the consonance fix. For now Alt+U in manual fork mode repeats the selected note.
