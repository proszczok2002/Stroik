# Stroik 1.05 / Stroik 1.05

## Polski

**Alt+U** w trybie kamertonu włącza lub wyłącza automatyczne uderzenia. Wyłączenie zatrzymuje timer i ucisza obecnie grany ton.

Aktualizator lepiej obsługuje chwilowe błędy sieci i przerwane pobieranie. Wynik automatycznego sprawdzania jest widoczny w zakładce **Ustawienia**, a ręczny przycisk pozwala ponowić próbę. Program sprawdza możliwość zapisu w folderze EXE przed zamknięciem starej wersji. Po udanej podmianie ponawia usunięcie starej kopii, gdy plik był chwilowo zablokowany. Każdy pobrany EXE nadal musi przejść kontrolę SHA-256.

Pobierz samodzielny, niepodpisany cyfrowo Stroik.exe dla Windows x64. Plik Stroik.exe.sha256 służy do weryfikacji. ZIP zawiera EXE, sumę, instrukcje PL/EN i licencję. Starsze wersje mogą zaproponować aktualizację z GitHub przy uruchomieniu.

## English

**Alt+U** toggles automatic strikes in tuning fork mode. Turning it off stops the timer and silences the currently playing tone.

The updater handles transient network errors and interrupted downloads more reliably. The automatic check result is visible in **Settings**, and the manual button retries the check. The app verifies write access to the EXE folder before closing the old version. After a successful replacement, it retries deleting the old copy if the file was briefly locked. Every downloaded EXE must still pass SHA-256 verification.

Download the self-contained, unsigned Stroik.exe for Windows x64. Stroik.exe.sha256 verifies the download. The ZIP includes the EXE, checksum, Polish and English guides, and license. Earlier versions can offer a GitHub update at startup.
