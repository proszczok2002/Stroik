# Stroik 1.09 / Stroik 1.09

## Polski

- Okno proponujące aktualizację pokazuje teraz zmiany z opisu nowego wydania na GitHubie. Opis można przewijać i czytać czytnikiem ekranu przed wybraniem „Tak, pobierz i zainstaluj”. Jeśli wydanie nie ma polskiego opisu, program jasno o tym informuje.
- W Ustawieniach przycisk „Ostatnie zmiany” pokazuje opis aktualnie zainstalowanej wersji, dostępny również bez internetu.
- Dodano przycisk „O programie” z opisem zastosowania Stroika oraz informacją: wykonawca Proszczok z Codex, pomysłodawca Witold.
- Dodano przyciski strony Proszczoka i dobrowolnego wsparcia przez PayPal lub Revolut. Otwierają podane strony w przeglądarce; żadne płatności nie odbywają się w Stroiku.

Pobierz samodzielny plik Stroik.exe dla Windows x64. Plik Stroik.exe.sha256 pozwala sprawdzić sumę pobranego EXE. ZIP zawiera EXE, sumę, instrukcje po polsku i angielsku oraz licencję.

## English

- The update prompt now shows the new release's changes from GitHub. The text can be scrolled and read with a screen reader before choosing “Yes, download and install”. If there is no English description, the app says so clearly.
- The “Latest changes” button in Settings shows the installed version's notes, including when offline.
- The “About Stroik” button explains the app's purpose and credits Proszczok with Codex as creator and Witold for the original idea.
- Buttons for Proszczok's website and voluntary PayPal or Revolut support open the supplied pages in a browser. Stroik does not process payments.

Download the self-contained Stroik.exe for Windows x64. Stroik.exe.sha256 verifies the downloaded EXE. The ZIP includes the EXE, checksum, Polish and English guides, and license.
