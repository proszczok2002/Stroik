# Stroik 1.04 / Stroik 1.04

## Polski

Wersja 1.04 dodaje nawigację bez dotykania komputera: po dobrym wyniku dwa oddzielne szybkie uderzenia w ten sam dźwięk przechodzą do następnej pozycji. Można to wyłączyć; Ctrl+N przechodzi ręcznie. Przy pianinie dostępne są kolejności od wybranej nuty: rosnąca, naprzemienne bloki po pięć półtonów oraz naprzemienne bloki całotonowe. Wariant całotonowy pomija pozostałe nuty, które trzeba nastroić osobno. Te schematy są pomocą nawigacyjną, a nie gwarancją bezpiecznego rozkładu naprężeń.

Dodano tekstowy przewodnik po klawiaturze pianina oraz opcjonalną klawiaturę z oznaczoną nutą i wskaźnik odchyłki na żywo. Przy wykrytym czytniku ekranu grafika domyślnie jest wyłączona; można ją włączyć ręcznie. Detekcja czytnika jest niepewna. W ustawieniach jest ręczna korekta odczytu mikrofonu od −100 do +100 centów.

Poprawiono opisy fizycznego położenia strun. Ukulele standardowe: od podłogi A4–E4–C4–G4. Wariant z zamienionymi A/G: G4–E4–C4–A4. Wybór zapisuje się w profilach. Gitara: od podłogi E4–H3–G3–D3–A2–E2; G to struna 3.

Pobierz samodzielny, niepodpisany cyfrowo Stroik.exe dla Windows x64. Stroik.exe.sha256 służy do weryfikacji. ZIP zawiera EXE, sumę, instrukcje PL/EN i licencję. Poprzednie wersje mogą zaproponować aktualizację z GitHub po uruchomieniu.

Rozpoznawanie dwóch uderzeń i pomiar mikrofonem zależą od sprzętu i instrumentu. Rzeczywiste działanie z NVDA, mikrofonem i instrumentem wymaga sprawdzenia na sprzęcie. Przed pracą przy starym pianinie skonsultuj jego stan i docelowy strój z technikiem.

## English

Version 1.04 adds hands-free navigation: after an in-tune result, two separate quick strikes at the same pitch advance to the next target. This can be disabled; Ctrl+N advances manually. Piano order choices are ascending, alternating five-semitone blocks, and alternating whole-tone blocks. The whole-tone plan skips the remaining notes, which need separate tuning. These plans guide navigation and do not guarantee safe tension distribution.

A piano keyboard text guide, an optional marked virtual keyboard, and a live deviation meter are included. Graphics default to off when a screen reader is detected and can be switched on manually. Screen reader detection is best effort. Settings also include a manual microphone reading correction from −100 to +100 cents.

String position descriptions have been corrected. Standard ukulele, floor to ceiling: A4–E4–C4–G4. Swapped A/G: G4–E4–C4–A4. Profiles save the choice. Guitar, floor to ceiling: E4–B3–G3–D3–A2–E2; G is string 3.

Download the self-contained, unsigned Stroik.exe for Windows x64. Stroik.exe.sha256 verifies the download. The ZIP includes the EXE, checksum, Polish and English guides, and license. Earlier versions can offer the GitHub update at startup.

Double-strike recognition and microphone measurement depend on hardware and instrument. Real NVDA, microphone and instrument behavior still needs hardware testing. Consult a technician about the condition and target pitch of an old piano.
