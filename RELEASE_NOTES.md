# Stroik 1.27

## Polski

Stroik 1.27

- Nowe profile zaczynają od hybrydy głośnikowej. Rosnący plan pianina zaczyna się od A subkontra (A0). Stroik zachowuje zapisane ustawienia.
- W ustawieniach wybierz komunikaty w centach, hercach lub w obu jednostkach w wybranej kolejności. Co piąta pozycja planu może uruchamiać kontrolę kwinty.
- Kamerton ma fabryczną kalibrację dla 71 nut i łagodniejsze wyższe składowe basu. Przejście w trybie kamertonu wymaga dwóch krótkich stuknięć rozdzielonych ciszą.
- Przełącznik w zakładce mapowania pokazuje, czy używasz mapy, czy stroju standardowego. Wyłączenie mapy zachowuje jej pomiary.
- Kalibrator 1.0.2 dla Windows ma automatyczne uderzanie kamertonu i suwak wyższych harmonicznych basu. Ctrl+O otwiera JSON, a Ctrl+S zapisuje zmiany do tego samego pliku. Pierwszy zapis pozwala wybrać nazwę i folder. Oba wydania Stroika czytają stary i nowy format kalibracji.
- Na liście dźwięków wpisz np. C4. Ctrl+góra/dół zmienia oktawę. Alt+M włącza i wyłącza mikrofon.

## English

Stroik 1.27

- New profiles start in speaker hybrid. An ascending piano plan starts at A0. Stroik keeps existing settings.
- Choose cents, hertz, or both in either order for announcements. You can check a fifth at every fifth position in the tuning plan.
- The fork has factory calibration for 71 notes and softer upper bass partials. Fork-mode navigation requires two short taps separated by silence.
- The switch in Instrument Mapping shows whether map or standard tuning is active. Switching to standard keeps the map readings.
- Windows Calibrator 1.0.2 has automatic preview and an upper-bass-harmonics slider. Ctrl+O opens a JSON file and Ctrl+S saves changes to the same file. The first save lets you pick its name and location. Both Stroik editions can read older and newer calibration files.
- Type a note such as C4 in the target list. Ctrl+Up/Down changes octave. Alt+M toggles the microphone.

## Deutsch

Stroik 1.27

- Neue Profile starten im Lautsprecher-Hybridmodus. Ein aufsteigender Klavierplan beginnt bei A0. Bestehende Einstellungen bleiben erhalten.
- Ansagen können Cent, Hertz oder beide Einheiten in beliebiger Reihenfolge enthalten. An jeder fünften Position lässt sich eine Quinte prüfen.
- Für 71 Töne gibt es eine Werkskalibrierung. Hohe Bass-Obertöne sind gedämpft. Im Stimmgabelmodus wechseln zwei kurze, durch Stille getrennte Klopfzeichen zum nächsten Ton.
- Der Schalter zeigt, ob Instrumentenkarte oder Standardstimmung aktiv ist. Messwerte bleiben beim Wechsel erhalten.
- Der Windows-Kalibrator 1.0.2 bietet automatische Wiedergabe und einen Regler für hohe Bass-Obertöne. Strg+O öffnet eine JSON-Datei, Strg+S speichert Änderungen in derselben Datei. Beide Stroik-Versionen lesen alte und neue Kalibrierdateien.
- Geben Sie z. B. C4 in der Tonliste ein. Strg+Pfeil hoch/runter wechselt die Oktave. Alt+M schaltet das Mikrofon.

## Русский

Stroik 1.27

- Новые профили запускаются в гибридном режиме с динамиком. Восходящий план для пианино начинается с A0. Сохранённые настройки сохраняются.
- Для сообщений можно выбрать центы, герцы или обе единицы в любом порядке. Квинту можно проверять на каждой пятой позиции плана.
- Для 71 ноты добавлена заводская калибровка и смягчены верхние гармоники баса. В режиме камертона для перехода нужны два коротких стука, разделённых тишиной.
- Переключатель показывает, активна ли карта инструмента. При переходе на стандартный строй измерения сохраняются.
- Калибратор 1.0.2 для Windows воспроизводит ноту автоматически и регулирует верхние гармоники баса. Ctrl+O открывает JSON, Ctrl+S записывает изменения в тот же файл. Обе версии Stroik читают старые и новые файлы калибровки.
- Введите в списке ноту, например C4. Ctrl+стрелка вверх/вниз меняет октаву. Alt+M переключает микрофон.

## Français

Stroik 1.27

- Les nouveaux profils démarrent en mode hybride avec haut-parleurs. Un plan de piano ascendant commence à A0. Stroik conserve les réglages précédents.
- Choisissez les cents, les hertz ou les deux dans l’ordre voulu. La quinte peut être vérifiée à chaque cinquième position du plan.
- Le diapason dispose d’un étalonnage d’usine pour 71 notes et d’harmoniques supérieures plus douces dans les graves. Deux coups brefs séparés par un silence font avancer en mode diapason.
- Le commutateur indique si le profil mesuré est actif. Le retour à l’accord standard conserve les mesures.
- L’étalonneur Windows 1.0.2 propose une lecture automatique et un réglage des harmoniques supérieures des graves. Ctrl+O ouvre le JSON et Ctrl+S enregistre dans le même fichier. Les deux éditions lisent les anciens et les nouveaux fichiers.
- Saisissez une note comme C4 dans la liste. Ctrl+Haut/Bas change d’octave. Alt+M commande le microphone.

## Español

Stroik 1.27

- Los perfiles nuevos arrancan en el modo híbrido con altavoces. Un plan ascendente de piano empieza en A0. Stroik conserva los ajustes guardados.
- Elige cents, hercios o ambas unidades en el orden deseado. Puedes comprobar una quinta en cada quinta posición del plan.
- El diapasón incluye calibración de fábrica para 71 notas y armónicos superiores más suaves en los graves. Para avanzar en el modo diapasón se requieren dos golpes breves separados por silencio.
- El interruptor indica si el mapa está activo. Volver a la afinación estándar conserva las mediciones.
- El calibrador 1.0.2 para Windows incluye reproducción automática y regulación de armónicos superiores de graves. Ctrl+O abre el JSON y Ctrl+S guarda en el mismo archivo. Ambas ediciones leen los archivos de calibración antiguos y nuevos.
- Escribe una nota como C4 en la lista. Ctrl+Arriba/Abajo cambia de octava. Alt+M activa o desactiva el micrófono.
