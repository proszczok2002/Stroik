# Stroik 1.18

## Polski

- Lista dźwięków pianina zawiera nazwę oraz położenie klawisza względem grup dwóch i trzech czarnych klawiszy, także dla dźwięków podwyższonych.
- W widoku dla początkujących zmiana celu strzałkami lub przyciskiem Następny dźwięk zgłasza nazwę i opis położenia. Widok klasyczny zachowuje krótszy komunikat.
- Dokumentacja PL/EN uzupełniona. Zachowano działanie kamertonu, współbrzmień i aktualizatora; pełne testy regresji obejmują także rzeczywisty sygnał PCM po zdarzeniach interfejsu.

Nie wykonano odsłuchu NVDA ani strojenia prawdziwego instrumentu na komputerze zgłaszającym problem.

## English

- Piano note options include the note name and physical position relative to groups of two and three black keys, including accidentals.
- In Beginner view, arrow and Next note changes announce the note and its position. Classic keeps concise announcements.
- Polish/English documentation updated. Fork, interval and updater behavior is retained; regression includes actual generated PCM after UI events.

Human NVDA listening and real-instrument tuning on the affected computer were not performed.
