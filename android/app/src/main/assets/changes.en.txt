Stroik Android 1.03

Improved screen reader focus retention. Changing method, consonance, instrument or tap listening updates the relevant fields without recreating the whole screen. Tab buttons keep their identity; choosing the current tab again does not refresh the form. Language and theme changes restore the corresponding control.

Numeric fields use labels and hints so their description does not mask the entered value. Note/octave synchronization no longer repeats user actions. Added real accessibility-focus retention tests in PL/EN.

The APK uses the existing signing key. Android confirms installation; the earlier Play Protect warning and test scope are documented.
