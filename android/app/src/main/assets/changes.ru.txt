Stroik Android 1.11

- Новые профили запускаются в гибридном режиме с динамиком. Восходящий план для пианино начинается с A0. Сохранённые настройки сохраняются.
- Для сообщений можно выбрать центы, герцы или обе единицы в любом порядке. Квинту можно проверять на каждой пятой позиции плана.
- Для 71 ноты добавлена заводская калибровка и смягчены верхние гармоники баса. В режиме камертона для перехода нужны два коротких стука, разделённых тишиной.
- Переключатель показывает, активна ли карта инструмента. При переходе на стандартный строй измерения сохраняются.
- Калибратор 1.0.2 для Windows воспроизводит ноту автоматически и регулирует верхние гармоники баса. Ctrl+O открывает JSON, Ctrl+S записывает изменения в тот же файл. Обе версии Stroik читают старые и новые файлы калибровки.
- Ползунок позволяет ввести ноту, например C4, и сменить октаву действиями TalkBack. Если включено удержание экрана, после ручного выключения экрана результаты не озвучиваются. При отключённой опции озвучивание работает и с погашенным экраном.
