# Stroik Android 1.0

## Polski

Pierwsze natywne wydanie Stroika na Androida 11 i nowszego. Interfejs polski i angielski opiera się na standardowych kontrolkach z dużymi polami dotykowymi i opisanymi polami.

- Kamerton, stroik mikrofonowy, hybryda głośnikowa i słuchawkowa.
- Pianino, gitara, ukulele w dwóch układach, skrzypce, bas i tryb chromatyczny; tradycyjne nazwy i lista oktaw.
- Kwinty i oktawy osobno lub razem eksperymentalnie, korekta mikrofonu, dwa uderzenia, plany kolejności i opcjonalna grafika.
- Profile JSON, jasny/ciemny motyw, instrukcja, informacje o autorach i wsparcie.
- Aktualizator GitHub weryfikuje APK i przekazuje instalację do systemowego okna Androida. Ustawienia mają pozostać przy aktualizacji.

Na POCO F8 Ultra z Androidem 16 przeszły 1831 testów kontrolek i zdarzeń dostępności oraz 7 sprawdzeń rzeczywistego nagrywania/odtwarzania. TalkBack pozostał włączony. Nie jest to potwierdzenie pełnego odsłuchu przez człowieka; rzeczywiste instrumenty i odsłuch słuchawkowy wymagają prób. Szczegóły: android/DEVICE_TESTS.md.

Pobierz Stroik-Android-1.0.apk. Android zapyta o zgodę na instalację i mikrofon. Nie odinstalowuj aplikacji przed przyszłą aktualizacją. Suma jest w pliku .apk.sha256.

## English

Initial native Stroik release for Android 11+. Polish and English interfaces use standard controls with large touch targets and labelled inputs.

- Tuning fork, microphone tuner, speaker and headphone hybrid practice.
- Piano, guitar, two ukulele layouts, violin, bass and chromatic mode; traditional note names and octave selection.
- Separate or experimental simultaneous fifth/octave checks, microphone correction, double strikes, note order and optional graphics.
- JSON profiles, light/dark theme, guide, credits and support.
- GitHub updater validates the APK and uses Android's system installation confirmation, retaining app settings.

On a POCO F8 Ultra with Android 16, 1831 control/accessibility event assertions and 7 actual capture/playback checks passed with TalkBack enabled. This does not establish complete human speech listening, instrument accuracy or headphone monitoring. See android/DEVICE_TESTS.md.

Download Stroik-Android-1.0.apk. Android asks for installation and microphone consent. Do not uninstall before a future update. Verify with the .apk.sha256 file.
